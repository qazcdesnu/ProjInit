# 완료 보관 M4 첫 적용

이 문서는 닫힌 마일스톤 M4의 완료 기록을 보관한다. M4의 태스크는 취소되었다. 기록 형식은 [작업 관리 규칙](TaskRule.md#5-기록-형식)을 따르며, 아직 닫히지 않은 마일스톤의 기록은 [완료](Done.md)에 있다.

## I17 AgentVis를 ProjInit으로 전환하지 않기로 함

- 시작일: 2026-10-31
- 완료일: 2026-10-31
- 근거 문서: [제품 비전](ProductVision.md#2-출발점)

### 계획
- 제품 비전 2절의 AgentVis 전환 계획을 지우고, M4-T1을 취소한다.

### 진행 기록
- 2026-10-31: 로드맵에 M4-T1(AgentVis 전환)만 남았다고 알리자, 사용자가 "AgentVis는 지금 잘 굴러가고 있고 실제로 필요한 프로젝트니 함부로 변경하지 않겠다. 전환은 필요한 기능이 아닌 것 같다"고 했다.
- 2026-10-31: 제품 비전 2절을 고치고 M4-T1을 취소했다. M4의 유일한 태스크라 M4가 닫혀, 이 기록과 M4-T1 취소 기록을 `docs/Done-M4.md`에 두었다.

### 결정 사항
- AgentVis는 ProjInit으로 전환하지 않는다. AgentVis의 규칙이 바뀌면 ProjInit에 필요한 것만 골라 이슈로 반영한다.
- 이미 진행 중인 기존 폴더를 ProjInit으로 옮기는 기능(지금 `init`은 파일이 있으면 거부한다)은 필요해지면 그때 정한다.

### 변경 파일
- `docs/ProductVision.md`, `docs/Roadmap.md`, `docs/Issue.md`, `docs/Done.md`, `docs/Done-M4.md`(신규)

### 결과
- 남은 로드맵 태스크가 없다. 다음 일은 `Jjabtero`에서 쓰며 나오는 문제다.

### 검증
- `uv run projinit check`: 모두 통과
