# 자료 폴더 규칙

이 문서는 프로젝트 밖에서 가져온 자료를 두는 두 폴더, 참고 자료 폴더 `reference/`와 기존 프로젝트 폴더 `legacy/`의 규칙을 정한다. 두 폴더는 문서도 코드도 아니며, 자료의 성격이 달라 따로 둔다. 전체 문서 목록은 [문서 인덱스](index.md)에서 확인한다.

## 1. 두 폴더

| 폴더 | 두는 것 | 성격 | 목록 문서 |
| --- | --- | --- | --- |
| `reference/` | 개발하면서 계속 참고하는 자료: 명세, 논문, 외부 API 문서, 디자인 시안, 샘플 데이터 등 | 살아 있는 자료. 개발 중에 더하고 고치고 지운다. | `docs/Reference.md` |
| `legacy/` | ProjInit 없이 작업하던 기존 개발 프로젝트 | 아카이브. 넣은 뒤로는 고치지 않는다. | `docs/Legacy.md` |

- 두 폴더는 필요할 때 만든다. 초기화는 만들지 않는다.
- 폴더 위치는 [설정](VerificationTools.md#11-설정)의 `paths.reference`, `paths.legacy`로 바꿀 수 있다. 목록 문서의 이름은 바꾸지 않는다.
- 자료 폴더는 코드 루트가 아니다. 제품 코드는 자료 폴더의 파일을 불러오거나 실행하지 않는다. 자료의 코드나 데이터가 제품에 필요하면 코드 루트에 새로 만들고, 그 근거로 자료를 문서에서 링크한다.
- 비밀 정보(키, 비밀번호, 개인 정보)는 넣지 않는다. 내려받을 수 있는 큰 자료는 파일을 넣지 않고 목록 문서에 출처만 적어도 된다.

## 2. 목록 문서

자료 폴더의 파일은 문서가 아니라서 [문서 인덱스](index.md)에서 링크를 따라 찾을 수 없다. 그래서 폴더마다 목록 문서를 두고, 에이전트와 사람은 목록 문서에서 자료를 찾는다.

- 자료 폴더에 파일이 하나라도 있으면 그 폴더의 목록 문서가 있어야 하고, 인덱스에서 링크한다.
- 목록 문서는 폴더의 모든 파일을 링크한다. 폴더를 링크하면 그 아래 모든 파일을 링크한 것으로 본다. 파일이 많은 자료(내려받은 문서 묶음, 기존 프로젝트 전체)는 폴더 하나를 링크한다.
- 항목마다 무엇인지, 출처(주소나 받은 곳), 넣은 날짜를 적는다.

```markdown
- [결제 API 명세](../reference/payment-api.pdf): 결제 대행사의 REST API 명세. 출처: https://example.com/docs. 넣은 날짜: 2026-11-01.
```

- 자료 폴더 안 코드 파일 링크는 [포인터 규약](Traceability.md)의 코드 포인터가 아니다. 파일이 있는지만 검사한다.

## 3. 참고 자료 폴더 `reference/`

- 자료를 더하거나 고치거나 지우는 일도 작업 ID가 있는 작업 안에서 한다. 같은 작업에서 목록 문서도 고친다.
- 자료가 바뀌어 그 자료를 근거로 쓴 문서가 어긋나면, 같은 작업에서 문서를 고치거나 이슈로 등록한다.

## 4. 기존 프로젝트 폴더 `legacy/`

- 기존 프로젝트 하나를 `legacy/<이름>/`에 통째로 복사한다. 프로젝트마다 하위 폴더 하나를 쓴다.
- 기존 프로젝트의 `.git` 폴더는 빼고 넣는다. 저장소 안의 저장소는 내용이 커밋되지 않는다. 기존 이력이 필요하면 목록 문서에 원래 저장소 주소를 적는다.
- 의존성과 빌드 산출물(`node_modules/`, `.venv/`, `build/`, `dist/`, `target/` 등)은 빼고 넣는다.
- 넣은 뒤로는 아카이브다. 커밋된 기존 프로젝트의 파일은 고치거나 지우거나 옮기지 않으며, 그 프로젝트 폴더에 새 파일을 더하지도 않는다. 기존 코드를 이어서 쓰려면 코드 루트로 복사한 뒤 거기서 고친다.
- 다른 기존 프로젝트를 더 넣는 것은 새 하위 폴더로 한다.
- 기존 프로젝트는 처음에 제품 비전, 시스템 구조, 첫 로드맵 초안의 근거가 되고([작업 관리 규칙의 첫 작업](TaskRule.md#48-첫-작업)), 그 뒤로는 예전 동작이나 결정을 확인할 때 읽는다.

## 5. 검증

이 규칙은 [자료 폴더 검사기](VerificationTools.md#15-자료-폴더-검사기)가 검사한다.
